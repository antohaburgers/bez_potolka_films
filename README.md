# БЕЗ ПОТОЛКА

Вертикальный аниме-сериал о работе, собеседованиях и офисной тоске. 20–40 секунд, русский диалог, абсурдный юмор.

## Этап 1 — кастинг голосов

Вкладка Actions → Voice casting → Run workflow. После успешного прогона скачайте артефакт `voice-casting`. Сравните отдельные MP3 и общий файл `casting.mp3`. Используется Silero v5 CIS Base (MIT), CPU, без API-ключей. Стандартный runner Ubuntu в публичном репозитории. Артефакты хранятся 1 день для экономии хранения.

Модель требует проверки ударений. Публикация и регулярный запуск пока выключены: сперва подтверждаем голоса и пилот.
