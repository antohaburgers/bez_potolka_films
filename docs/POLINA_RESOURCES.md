# Полина — ресурсы и контракт движка

Утверждён прототип v0.5: эталон, пять областей волос, отдельные веки, дыхание, локальное движение головы, восемь форм рта с таймингами фонем. Вариант рта v0.5.1 отклонён. Эмоции и жесты пока концепт, не анимационные ресурсы.

## План структуры (бинарные ресурсы ещё не загружены)
- hockey/assets/polina/v1/base.png — эталон
- hockey/assets/polina/v1/eyes/ — состояния век
- hockey/assets/polina/v1/mouth/ — rest, a, e, i, o, u, fv, small
- hockey/assets/polina/v1/emotions/ — совместимые слои бровей, глаз и выражений
- hockey/assets/polina/v1/gestures/ — совместимые слои рук, позы, маски
- hockey/assets/polina/v1/rig.json — координаты, порядок слоёв, параметры движения
- hockey/animation/ — переиспользуемые алгоритмы
- hockey/tests/ — тестовые данные и проверки

## Контракт сценария (проект, не реализован)
Реплика содержит text, emotion, gesture, head, hair, effect, camera. Неизвестные значения отклоняются; неподготовленные комбинации не считаются поддержанными. Эмоция управляет базовым выражением, моргание — состоянием глаз, речь — ртом, жест — руками/позой. Слои лица компонуются до общего преобразования головы, физика волос и дыхание используют совместимую геометрию. Не перегенерировать ведущую для каждой реплики.

## Статус
Существующий smoke-renderer на GitHub использует геометрическую заглушку. Утверждённый локальный прототип v0.5 ещё не интегрирован и не прошёл облачную сборку. Бинарные PNG и тестовый WAV подготовлены локально; необходимо перенести их в GitHub и проверить контрольные суммы, затем воспроизводимость. Тестовый eSpeak не является голосом Полины; для Silero требуется отдельный механизм таймингов. Публикация отключена.
