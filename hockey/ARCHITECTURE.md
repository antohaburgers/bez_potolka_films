## Контур
Официальные новости и первичные источники → черновик с датой и ссылками → фактчек (факт/слух/мнение) → согласование конкретной ревизии сценария → сборка → проверка ffprobe и визуальная проверка → архив → отдельное разрешение публикации.
Без платного API: редакционный этап в ChatGPT, производство в стандартных GitHub Actions. Plus не является API-кредитом и сам по себе не гарантирует автоматический доступ к редактору из Actions. Расписание редакции и передачу сценария проверяем отдельно.
GitHub Pages — интерфейс только для публичных несекретных данных. Для закрытых черновиков и управления на первом этапе используем авторизованный GitHub UI; позже безопасный серверный OAuth/прокси, если доступен в бесплатной квоте. Никаких PAT в JavaScript. Не хранить закрытые сценарии в публичном репозитории.

## Движок
0.1: JSON → проверка входа → Silero (WAV на реплику) → таймлайн по фактической длительности → RMS-анимация рта (не фонемы) → Pillow (540x960 прототип, апскейл до 1080x1920) → FFmpeg H.264/AAC → ffprobe → артефакт. Субтитры в кадре + SRT. Технический тест не является выпуском; временная геометрическая заглушка вместо Вари.
0.2: согласованный образ, набор слоёв (тело, волосы, глаза, рот, руки), эмоциональные состояния, моргание, дыхание, жесты, фон; нативный рендер 1080x1920; визуальная проверка.
0.3: новости, статистика, вставки, камера, нормализация звука, оригинальная музыка и SFX, проверка лицензий.
0.4: редакция и панель, архив и защита от повторов.
0.5: официальные адаптеры публикации после отдельного согласия и проверки авторизации.

## Защита и данные
Статусы draft → reviewed → approved → rendering → rendered → quality_checked → publication_approved → published/failed.
Согласование привязать к SHA-256 канонического JSON; изменение сбрасывает согласование. Производственный запуск проверяет статус и хеш из доверенного источника. Публикация отключена; тестовый workflow без токенов записи. Для каждого факта — source URL, время доступа, тип утверждения; для каждого ресурса — автор, лицензия, права на коммерческое использование. Голос пока временный, условия модели проверить перед коммерческим использованием. Использовать только собственные или лицензированные изображения/звук. Не использовать записи матчей без прав.
Лимиты: стандартный публичный runner, timeout, concurrency, короткое хранение тестовых артефактов. Бесплатность внешних платформ и сроки хранения не гарантированы. Архивировать только согласованные материалы и не делать публичный архив черновиков.
